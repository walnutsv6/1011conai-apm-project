# Pyxel BGM Player

既存の音声リソースを選曲して聴ける、ROM不要の独立したPyxelアプリを作る。音声抽出とは別工程として扱い、入力済みの音符・音量・独自音色・テンポ・チャンネル別の冒頭とループを保持する。

## 作成の流れ

1. 入力の `.pyxres`、埋め込みメタデータまたは同名JSON、曲目情報を確認する。[入力と組み込み](references/player-input.md) の形式へ必要な項目を合わせる。ROMが必要な抽出・再変換はこのスキルの範囲に含めない。
2. `assets/player.py` と `assets/audio_runtime.py` をプロジェクト内の専用フォルダーへコピーして使う。既存プレイヤーの更新なら以下の操作・状態規則を同等に実装する。画面のタイトルや曲名は対象に合わせる。
3. 実際のPyxelで全曲の読み込み・音色・冒頭→ループ・有限再生と、停止中/一時停止中/再生中の操作を確認する。[検証と配布](references/validation-packaging.md) の確認項目を使う。
4. `scripts/package_player.py` で実行に必要なファイルだけを `.pyxapp` にまとめ、配布ZIPを作る。抽出コード、ROM、録音、検証ファイル、他ゲームのコードは入れない。開発用のソースはプロジェクト側へ残す。

## 操作と再生状態

| 操作 | キーボード | ゲームパッド1 |
| --- | --- | --- |
| 前/次の曲を選ぶ | ↑/←、↓/→ | 十字キーの上/左、下/右 |
| 再生・一時停止・再開 | Space | A |
| 現在の曲を先頭へ戻す | R | B |
| 終了 | Esc | START |

- 起動時は最初の曲を選択して**停止**する。A/Spaceが押されるまで `pyxel.play()` を呼ばず、経過時間も進めない。
- 再生中のA/Spaceは、その時点の再生位置を保って一時停止する。一時停止中のA/Spaceはその位置から再開する。
- 停止中または一時停止中の選曲は、新しい曲を先頭に置き、無音のまま待つ。A/Spaceを押して初めて再生する。
- 再生中の選曲は、選んだ曲の先頭からすぐに再生する。
- B/Rは先頭へ戻し、再生状態を維持する。停止中や一時停止中に押しても再生を始めない。
- 有限曲は全パートの終了後に停止する。次のA/Spaceで先頭から再生する。
- A/Space、B/R、START/Escは押下の立ち上がりで1回だけ処理する。キーボードとゲームパッドの同じ操作をまとめ、同時押しで二重に処理しない。Pyxelの `GAMEPAD1_BUTTON_DPAD_*`、`GAMEPAD1_BUTTON_A/B/START` を使う。

画面には選択曲、停止/一時停止/再生中、再生位置、曲一覧、操作を表示する。選曲時に再生状態を無条件で「再生中」へ戻さない。冒頭境界でのみチャンネルの再生計画を切り替え、毎フレーム音を再トリガーしない。

## 配布形式

再生用ZIPのルートは原則 **`<name>.pyxapp` と `PLAY.txt` の2ファイル**とする。音声・曲目情報・再生処理はpyxapp内に含め、利用者が複数のソースやリソースを配置する作業をなくす。`PLAY.txt` に対応するPyxel版、`pyxel play <name>.pyxapp`、キーボードとゲームパッドの操作を記載する。

pyxappの起動にはPython/Pyxelの環境が必要で、ランタイムを同梱したOS実行ファイルではない。要求がpyxappの配布である限り、exe化やWeb公開へ作業を拡張しない。

## 付属コードと確認済み環境

- `assets/player.py`: 状態管理とキーボード/ゲームパッド操作のひな型。
- `assets/audio_runtime.py`: 埋め込み独自音色の復元、4チャンネル補完、実際のSOUND尺による冒頭/ループ再生計画。
- `scripts/package_player.py`: 再生用ファイルだけをステージし、Pyxelの公式 `package` コマンドでpyxappと2ファイル構成のZIPを生成する。
- `scripts/self_test.py`: ROM不要の合成リソースで操作・ネイティブ再生・pyxapp起動・ZIP構成を検証する。

Python 3.11以上、Pyxel 2.9.9で確認。使用する環境の入力定数、独自Tone、package/play APIを確認して別版へ対応する。ゲームパッド定数への入力注入による検証と、接続された実機コントローラーでの確認を区別して報告する。
