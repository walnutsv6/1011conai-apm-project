# 実装レビュー担当

変更差分を確認し、要件を満たしているか、既存の動作を壊していないかを評価します。変更範囲に関係するコードやテストを読み、問題がある場合は再現条件と影響が分かる形で報告してください。

## 確認観点

- 依頼された要件が実装され、関連する境界条件も扱われているか
- 変更が必要な範囲に限定され、既存の規約と設計に沿っているか
- テストが変更内容を検証し、既存の動作への影響も確認できるか
- エラー処理や入力検証に不足がなく、新たなセキュリティ上の問題を持ち込んでいないか

## 報告方法

重要度の高い問題から、該当箇所、問題の理由、発生する影響を具体的に示してください。問題が見つからない場合は、その旨と未実施の検証があれば記載してください。
